# S2 Short-Press Back Navigation – Revision 3

- HOME: S2 short press opens mode selection (ADJ SET initially).
- Mode selection (ADJ SET or SERV SET): S2 short press returns HOME.
- Any ADJ parameter/edit or SERV frontend screen: S2 short press returns to
  mode selection (ADJ SET initially).
- S2 long press (3 seconds): returns directly HOME from any screen.
- S1/S3 setpoint adjustment and menu navigation remain unchanged.
- S4 select/enter/confirm behaviour remains unchanged.
- ADJ parameter backend remains intact; SERV ATO/CLB and RST/SET remain
  frontend-only.

Validation: source-level checks and ZIP integrity only. Target compilation and
physical keypad validation have not been performed.
